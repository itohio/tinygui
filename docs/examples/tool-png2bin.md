# cmd/png2bin

Host tool that turns a PNG into a Go source file with an RGB565 `[]uint16` array for `widget.Bitmap16`. Part of [[examples]].

## Usage

```sh
GOTOOLCHAIN=local GOPROXY=off go run ./cmd/png2bin examples/choice/media/aquarium.png > examples/choice/icons/aquarium.go
```

Output (`cmd/png2bin/png2bin.go:69-93`): `package icons`, constants `<Name>Width` / `<Name>Height`, and `var <Name>Png = []uint16{…}`, ten values per line. `<Name>` is the file name without extension, title-cased (`:36-39`). This matches the committed `examples/choice/icons/*.go`, so they were most likely generated by this tool [INFERENCE: same layout; the source PNGs are not in the repo].

## Behaviour

- Colour conversion: `RGBATo565` keeps the top 5/6/5 bits of the 16-bit-per-channel `color.RGBA()` values (`:24-29`). Alpha is dropped, so transparent pixels become whatever colour the PNG stores under them (usually black).
- Pixel order: row-major, `img.At(x, y)` for every pixel (`:62-67`).

## Defects

- Accepts `.jpg`/`.jpeg` (`:41`) but always decodes with `image/png` (`:56`), so JPEGs fail ([[findings]] F-18).
- Package name `icons` is hard-coded (`:69`).
- Output is a `var` slice, which TinyGo places in RAM: 3 200 B per 40×40 icon ([[memory-and-buffers]]).
- Line breaks: the first output line carries 11 values, the rest 10 (`:79-90`, `i%max == 0 && i != 0` check after printing).
